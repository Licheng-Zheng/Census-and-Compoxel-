# Census-and-Compoxel

Might make a folder here in the future for people to look into, but this is mostly just somewhere for me to push code to so that i can run it on google colab. 

## Purpose
Use FlameGPU to simulate things. The boids models was made as a demo of the capabilities and make sure I could get it working. 
To run the boids model on your own machine, just clone the repo and run test_folder/main.ipynb and everything should work from there. I am trying to increase the usability by putting constants and variables into a folder that you can edit (so you don't have to get into the scary cuda and python code to tweak parameters).
